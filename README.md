# Fortune Cookies for Machines

`You will fix it in one line, then spend an hour making the one line look like you meant it.`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The joke is that agents obsess over making a one-line fix look intentional instead of just fixing it. The real punchline is that the rewrite usually introduces a subtle bug the original one-liner didn't have.
